# Examples

Set indent size to 4.

```sh
$ bash md-toc.sh examples/example_ja.md -s 4
* [これがタイトル](#これがタイトル)
    * [みだし 1](#みだし-1)
    * [みだし 2 スペース付き](#みだし-2-スペース付き)
    * [みだし 3　全角スペース付き](#みだし-3-全角スペース付き)
        * [スペースとは](#スペースとは)
            * [さらなるインデント](#さらなるインデント)
    * [終わりに 🤗](#終わりに-)
```

Without H1 tag.

```sh
$ bash md-toc.sh examples/example_ja.md -min 2
* [みだし 1](#みだし-1)
* [みだし 2 スペース付き](#みだし-2-スペース付き)
* [みだし 3　全角スペース付き](#みだし-3-全角スペース付き)
  * [スペースとは](#スペースとは)
    * [さらなるインデント](#さらなるインデント)
* [終わりに 🤗](#終わりに-)
```

Only H2 and H3 tags.

```sh
$ bash md-toc.sh examples/example_ja.md -min 2 -max 3
* [みだし 1](#みだし-1)
* [みだし 2 スペース付き](#みだし-2-スペース付き)
* [みだし 3　全角スペース付き](#みだし-3-全角スペース付き)
  * [スペースとは](#スペースとは)
* [終わりに 🤗](#終わりに-)
```
